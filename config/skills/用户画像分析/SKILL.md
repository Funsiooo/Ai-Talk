# Skill: 用户画像分析

对你在 AI-Talk 中的全部会话进行本地统计与 AI 分析，输出「提问习惯 / 关注点 / 提问方向 / 改进建议 / 注意问题」五维画像，并可一键导出为 HTML 分析报告。

## 使用方式

1. 在输入框中输入 `@skill`，在弹出的技能列表中选择「用户画像分析」；或进入技能商店，点击技能卡片后点「引用此技能」；
2. 引用成功后输入区会显示技能标签，在输入框写入消息并发送即可触发分析。可在消息中指定统计时段：
   - 写「今日」「今天」→ 仅统计今日会话；
   - 写「本周」「这周」→ 仅统计本周（周一起）会话；
   - 不写或写「整体」「全部」→ 统计全部历史会话。
3. 分析完成后，AI 会在对话中输出报告，报告底部提供「导出分析报告」按钮，可导出为独立的 HTML 文件。

## 数据来源与隐私

- 统计完全基于本地数据：`ai-talk-conversations.json`（会话与提问记录）、审计日志与 Token 用量统计。
- 分析过程会将「统计数据 + 提问样本 + 会话记忆摘要」发送给当前配置的模型服务商，由模型生成画像报告（与「对话记忆」技能行为一致）。
- 导出的 HTML 报告为本地文件，不会上传到任何服务端。

## 配置参数

| 参数 | 值 | 说明 |
|------|-----|------|
| type | system | 以 system prompt 方式注入分析指令 |
| temperature | 0.4 | 低温度确保分析稳定、客观 |
| 时段 | 今日 / 本周 / 整体 | 由输入内容中的关键词解析，未指定默认为整体 |
